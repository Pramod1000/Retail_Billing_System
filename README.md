# 🛒 Retail Billing System

A simple **Retail Billing System** developed using **Python and Tkinter**. The application provides a graphical interface for entering customer details, selecting products, calculating prices and taxes, and generating a detailed retail bill.

## ✨ Features

* 👤 Customer name and phone number entry
* 🧾 Automatic bill number generation
* 🧴 Cosmetics product section
* 🛒 Grocery product section
* 🥤 Other products section
* 💰 Automatic price calculation
* 🧮 Automatic tax calculation
* 📄 Bill generation
* 🧹 Clear bill option
* ❌ Exit option
* 🖥️ User-friendly Tkinter GUI

## 📦 Product Categories

### Cosmetics

* Bath Soap
* Face Cream
* Face Wash
* Hair Spray
* Body Lotion

### Grocery

* Rice
* Food Oil
* Daal
* Wheat
* Sugar

### Others

* Maza
* Coke
* Frooti
* Nimko
* Biscuits

The application calculates category-wise totals and applies a **5% tax** to each category.

## 🛠️ Technologies Used

* **Python**

* **Random Module**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/retail-billing-system.git
```

### 2. Open the project folder

```bash
cd retail-billing-system
```

### 3. Run the application

```bash
python app.py
```

No external Python packages are required because the project uses Python's built-in Tkinter and random modules.

## 🧾 How It Works

1. Enter customer details.
2. Enter the quantity of required products.
3. Click **Total** to calculate category-wise prices and taxes.
4. Click **Generate Bill** to display the bill.
5. Use **Clear** to clear the bill.
6. Use **Exit** to close the application.

The application displays the generated bill with the customer details, bill number, products, quantities, prices, and total amount.
